# Modest Style Website

A responsive fashion storefront showcasing modest dresses and outfits, with product images, prices, and discount labels. Built with plain HTML, CSS, and JavaScript.

## Features

- Responsive product-card layout
- Product names, images, current prices, and discounts
- Simple static site with no build step or dependencies

## Run locally

Open `index.html` in a browser. Product photos are stored in `Images/` and loaded by `script.js`.

## Project files

- `index.html` - page structure
- `style.css` - layout and styling
- `script.js` - product data and rendering
- `Images/` - product photos
- `ScreenShot_of_website.png` - project screenshot
